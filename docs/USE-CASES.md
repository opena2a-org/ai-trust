# Use cases

Practical guides for common ai-trust workflows. Each guide includes the exact commands, expected output, and what to do next. The output samples are checked against the current build by `src/docs-samples.test.ts`; registry values (scores, scan ages) are from the day the samples were captured and will differ when you run the commands.

| Use Case | Time | Description |
|----------|------|-------------|
| [Check before install](use-cases/check-before-install.md) | 2 min | Look up a package's trust score before adding it to your project |
| [Check an MCP server](use-cases/check-mcp-server.md) | 3 min | Verify an MCP server's trust level and understand what the levels mean |
| [Contribute scans](use-cases/contribute-scans.md) | 3 min | Share pseudonymous scan results to improve trust data for everyone |
